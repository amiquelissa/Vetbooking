## Instalação

Para configurar o ambiente de desenvolvimento, siga os passos abaixo:

1. Clone o repositório:
   ```bash
   git clone <URL-do-repositório>
   ```

2. Navegue até o diretório do projeto:
   ```bash
   cd VetBooking
   ```

3. Instale as dependências listadas no `requirements.txt`:
   ```bash
   pip install -r requirements.txt
   ```

## Uso

Para iniciar o servidor, execute o seguinte comando:

```bash
python app.py
```

Acesse as funcionalidades principais através do navegador em `http://localhost:8000`.

## Estrutura do Projeto

- `app.py`: Arquivo principal do servidor.
- `pages/`: Contém os arquivos HTML das páginas do site.
- `styles/`: Contém os arquivos CSS para estilização.
